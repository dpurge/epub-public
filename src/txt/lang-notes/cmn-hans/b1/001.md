## GitHub 推荐：RogueCleaner / Windows 流氓软件克星

你大概有过这种体验：本来只想装个输入法、网盘或看图工具，几天后却发现——右键菜单越来越长、开机越来越慢、浏览器多了陌生插件、后台多了一堆不知名的服务。更气人的是，这些软件卸载后往往没真正离开，只留下注册表残留、计划任务和自启动项。

GitHub 上的 RogueCleaner（流氓软件克星），就是专治这种“我没同意你就往我电脑里塞东西”的小工具，作者 aakk007 正是吾爱破解上的同名 ID。

### 和传统电脑管家不一样

RogueCleaner 不关心删除缓存、清理垃圾或加速电脑。它关心的是那些偷偷修改 Windows 行为的软件：右键菜单、开机自启、计划任务、后台服务、浏览器插件、文件关联残留。

覆盖位置很全，包括：

- 资源管理器右键菜单与 Shell 扩展
- “此电脑”里的网盘入口
- 启动注册表
- Windows 服务与计划任务
- Chrome、Edge、Firefox 的扩展与 Native Messaging Host
- 图片、视频、压缩包、Office 文档的打开方式残留

内置识别名单也很接地气：360、WPS/金山、百度网盘、夸克、搜狗、迅雷、钉钉、腾讯系、2345、Bandizip、猎豹、驱动工具、国产浏览器、手机助手、游戏大厅、PDF 捆绑等，基本把国产“常塞户”一网打尽。

### 把证据摆在你面前

列表优先显示普通人看得懂的内容，而不是让你对着注册表路径猜谜：

- **在哪里冒出来**：右键菜单、开机启动还是后台服务
- **你会看到什么**：真实菜单标题、服务名
- **影响说明**：开机自启还是接管某类文件
- **工具会怎么处理**：备份后删除注册表、禁用服务、弹出原厂卸载器，或仅提示

鼠标悬停任意一行，还会展开完整技术位置和证据。

容易被误伤的“默认打开软件”等项目只提示、不参与一键清理；疑似捆绑或弹窗组件即便有卸载命令，也必须由用户手动勾选后才会弹出卸载器。

### 把“手滑”的风险压到最低

项目的原则很克制：

- 打开软件默认不清理
- 扫描结果默认不勾选
- “仅提示”项目不会被自动勾选
- 清理前进行二次确认
- 涉及注册表与服务的操作需要管理员权限

每次清理都会生成一份备份批次，存入“流氓软件克星数据/backups”。出现问题时，可以在“恢复中心”按批次回滚注册表、被移动文件、服务与计划任务状态。

清理后还会逐项复扫，失败的残留会继续留在列表里——不偷偷替你做决定。

### 几条硬底线

作者定下的红线读起来很安心：

- 不常驻后台
- 不加壳
- 不混淆
- 不静默更新
- 不绕过软件自保护
- 不改写 UserChoice
- 不默认卸载主程序
- 不删除用户文档

它会被 360、火绒等安全软件的启发式规则误报为“系统工具类风险”。因此，项目坚持不加壳、不混淆、不内嵌脚本，也不制作自解压一键包。

如需核对，下载 GitHub Releases 中的直出 EXE 文件，并对照 SHA-256 校验即可。

对于喜欢折腾 Windows、追求干净系统的用户，尤其是被国产软件“全家桶”困扰的人，这款开源小工具值得在 U 盘里常备一份。

它不会让你的电脑变快，但能让你清清楚楚知道：到底是谁，改了我的系统。

### Minimalizuje ryzyko „kliknięcia nie tam, gdzie trzeba”

Założenia projektu są bardzo zachowawcze:

- po uruchomieniu program domyślnie niczego nie usuwa
- wyniki skanowania nie są domyślnie zaznaczone
- elementy oznaczone jako „tylko informacja” nie są zaznaczane automatycznie
- przed czyszczeniem wymagane jest dodatkowe potwierdzenie
- operacje dotyczące rejestru i usług wymagają uprawnień administratora

Po każdym czyszczeniu tworzona jest osobna kopia zapasowa, zapisywana w folderze `dane RogueCleaner/backups`. Jeśli coś pójdzie nie tak, w „Centrum odzyskiwania” można według partii przywrócić rejestr, przeniesione pliki oraz stan usług i zaplanowanych zadań.

Po zakończeniu czyszczenia program ponownie skanuje każdy element. Pozostałości, których nie udało się usunąć, nadal pozostają na liście — narzędzie nie podejmuje za użytkownika ukrytych decyzji.

### Kilka twardych zasad

Czerwone linie wyznaczone przez autora brzmią naprawdę uspokajająco:

- program nie działa stale w tle
- nie jest pakowany przy użyciu packera
- nie stosuje zaciemniania kodu
- nie aktualizuje się po cichu
- nie omija mechanizmów samoochrony innych programów
- nie modyfikuje wartości UserChoice
- domyślnie nie odinstalowuje głównych programów
- nie usuwa dokumentów użytkownika

Reguły heurystyczne programów zabezpieczających, takich jak 360 czy Huorong, mogą błędnie rozpoznawać go jako „zagrożenie związane z narzędziem systemowym”. Dlatego projekt nie używa packera ani zaciemniania kodu, nie osadza skryptów i nie jest rozpowszechniany jako samorozpakowujący się pakiet instalowany jednym kliknięciem.

Jeśli chcesz to zweryfikować, pobierz bezpośredni plik EXE z sekcji GitHub Releases i porównaj jego sumę kontrolną SHA-256.

Dla osób, które lubią majsterkować przy Windowsie i cenią sobie czysty system — szczególnie tych, którym dają się we znaki „całe rodziny” chińskich programów — ten niewielki program open source zdecydowanie warto mieć na pendrivie.

Nie sprawi, że komputer zacznie działać szybciej, ale pozwoli ci dokładnie ustalić, kto zmienił twój system.

## Kluczowa gramatyka

Chiński jest językiem **topic-prominent**, a podstawowy szyk zdania często jest SVO. W tekście występują jednak konstrukcje, które wysuwają obiekt lub temat na początek:

| Konstrukcja | Znaczenie | Przykład |
|---|---|---|
| **把 + obiekt + czasownik** | podkreśla, co zostaje poddane działaniu | 把证据摆在你面前 *bǎ zhèngjù bǎi zài nǐ miànqián* — „położyć/przedstawić dowody przed tobą” |
| **被 + wykonawca + czasownik** | strona bierna | 被移动文件 *bèi yídòng wénjiàn* — „przeniesione pliki” |
| **是……的** | podkreślenie szczegółu zdarzenia | 作者正是同名 ID *zuòzhě zhèng shì tóngmíng ID* — „autorem jest właśnie osoba o tym samym ID” |

### Aspekt, czas i zmiana stanu

Chińskie partykuły aspektu nie oznaczają czasu, lecz sposób postrzegania czynności:

- **了 *le*** — zakończenie czynności lub nowy stan: 卸载后 *xièzǎi hòu* — „po odinstalowaniu”;  
- **过 *guò*** — doświadczenie: 你大概有过这种体验 *nǐ dàgài yǒu guò zhè zhǒng tǐyàn* — „prawdopodobnie miałeś takie doświadczenie”;  
- **着 *zhe*** — trwający stan (w tym tekście pojawia się przede wszystkim w konstrukcjach opisujących stan lub położenie).

Konstrukcja **越来越 + przymiotnik/przysłówek** oznacza „coraz bardziej / coraz…”: 菜单越来越长 *càidān yuèláiyuè cháng* — „menu staje się coraz dłuższe”, 开机越来越慢 *kāijī yuèláiyuè màn* — „uruchamianie systemu jest coraz wolniejsze”.

### Modyfikowanie rzeczownika

Zdanie lub wyrażenie przed **的 *de*** działa jak określenie rzeczownika:

- 不知名的服务 *bù zhīmíng de fúwù* — „nieznane usługi”;
- 用户手动勾选的项目 *yònghù shǒudòng gōuxuǎn de xiàngmù* — „elementy zaznaczane ręcznie przez użytkownika”.

W chińskim **的** może więc łączyć zarówno przymiotnik, jak i całe zdanie z rzeczownikiem. Rzeczowniki policzalne wymagają klasyfikatora po liczebniku, np. **一份备份批次 *yí fèn bèifèn pīcì*** — „jedna partia kopii zapasowej”; **一行 *yì háng*** — „jeden wiersz”.

### Inne ważne wzorce

- **只想……却……** — „chcieć tylko…, a jednak…”: 只想装个输入法，却发现…… *zhǐ xiǎng zhuāng ge shūrùfǎ, què fāxiàn…* — „chciał tylko zainstalować edytor, a jednak odkrył…”.
- **只……不……** — „tylko…, nie…”: 只提示、不参与一键清理 *zhǐ tíshì, bù cānyù yíjiàn qīnglǐ* — „tylko ostrzega, nie uczestniczy w czyszczeniu jednym kliknięciem”.
- **还会 + czasownik** — „dodatkowo będzie / nadal będzie”: 清理后还会逐项复扫 *qīnglǐ hòu hái huì zhúxiàng fùsǎo* — „po czyszczeniu ponownie sprawdzi każdy element”.
- **到底是谁……** — pytanie emfatyczne „kto właściwie…?”: 到底是谁改了我的系统 *dàodǐ shì shéi gǎi le wǒ de xìtǒng* — „kto właściwie zmienił mój system?”.

{end-text}
