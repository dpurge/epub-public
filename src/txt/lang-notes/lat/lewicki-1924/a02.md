# Na podwórzu

{start-vocabulary}
puella {N f} = dziewczynka
agna {N f} = jagnię (samica)
domina {N f} = pani (domu)
cena {N f} = posiłek; obiad
aqua {N f} = woda
bestia {N f} = zwierzę
parvus {Adj} = mały
gratus {Adj} = miły; drogi
parare {V} = przygotowywać
imperare {V} = rozkazywać (z celownikiem)
portare {V} = nieść; nosić
obtemperare {V} = być posłusznym (z celownikiem)
esse {V} = być
et {Conj} = i
{end-vocabulary}

---

{start-models}
parva puella = mała dziewczynka
parvae puellae = małej dziewczynce
agna grata = miłe jagnię
Parvae puellae agna grata est. = Małej dziewczynce jagnię jest miłe.

cena = posiłek
agnae cenam = posiłek dla jagnięcia
cenam parat = przygotowuje posiłek
Puella agnae cenam parat. = Dziewczynka przygotowuje posiłek dla jagnięcia.

domina = pani
puellis imperat = rozkazuje dziewczynkom
Domina puellis imperat. = Pani rozkazuje dziewczynkom.
aquam portate = nieście wodę
Agnis aquam portate, puellae! = Nieście wodę jagniętom, dziewczynki!

dominae = pani (komu)
obtemperant = są posłuszne
Puellae dominae obtemperant. = Dziewczynki są posłuszne pani.
bestiis aquam = wodę zwierzętom
Bestiis aquam portant. = Niosą zwierzętom wodę.
{end-models}

---

Parvae puellae agna grata est.
Puella agnae cenam parat.

Domina puellis imperat:
"Agnis aquam portate, puellae!"

Puellae dominae obtemperant.
Bestiis aquam portant.
