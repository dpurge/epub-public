{start-models lang=lat script=latn}
Minerva = Minerwa
patrona = patronka
patrona pugnarum = patronka walk
Minerva pugnarum patrona est. = Minerwa jest patronką walk.

Diana = Diana
domina = pani
silvarum domina = pani lasów
Diana autem est silvarum domina. = Diana zaś jest panią lasów.

ferae bestiae = dzikie zwierzęta
feras bestias = dzikie zwierzęta (biernik)
Feras bestias Diana non amat. = Diana nie kocha dzikich zwierząt.
sagittis = strzałami
Dea sagittis feras bestias necat. = Bogini strzałami zabija dzikie zwierzęta.

cervae bonae = dobre łanie
cervae bonae bestiae sunt = łanie są dobrymi zwierzętami
Sed cervae bonae bestiae sunt. = Lecz łanie są dobrymi zwierzętami.
Diana est patrona cervarum. = Diana jest patronką łań.

quis = kto
in silvam = do lasu
Quis in silvam properat? = Kto śpieszy do lasu?
Quem puellae adorant? = Kogo czczą dziewczęta?
Quid puellae in ara collocant? = Co dziewczęta kładą na ołtarzu?
{end-models}
