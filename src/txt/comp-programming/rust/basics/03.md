# 03

## Cel rozdziału

Rozdział 3 zbiera podstawowe elementy składni i modelu programowania w Ruście: zmienne, typy, funkcje, komentarze oraz sterowanie przepływem. To nie są idee unikalne dla Rusta, ale tutaj mają dość ścisłe, jawne reguły.

## Zmienne, mutowalność i shadowing

W Ruście zmienne są domyślnie niemutowalne. Mutowalność trzeba zadeklarować jawnie przez `mut`.

```rust
let x = 5;
let mut y = 5;
y = 6;
```

### Co zapamiętać

- `let` tworzy wiązanie nazwy z wartością,
- bez `mut` ponowne przypisanie jest błędem kompilacji,
- preferencja dla niemutowalności wspiera czytelność i bezpieczeństwo kodu.

### `const`

Stałe deklaruje się przez `const` i zawsze wymagają adnotacji typu:

```rust
const THREE_HOURS_IN_SECONDS: u32 = 60 * 60 * 3;
```

Różnice względem `let`:

- nie mogą być mutowalne,
- muszą mieć znany typ,
- wartość musi być stałym wyrażeniem obliczalnym w czasie kompilacji,
- mogą istnieć także w zakresie globalnym.

### Shadowing

Shadowing pozwala utworzyć nowe wiązanie o tej samej nazwie:

```rust
let x = 5;
let x = x + 1;

{
    let x = x * 2;
    println!("The value of x in the inner scope is: {x}");
}

println!("The value of x is: {x}");
```

Najważniejsze różnice między `mut` a shadowingiem:

- `mut` zmienia wartość tej samej zmiennej,
- shadowing tworzy nowe wiązanie,
- shadowing może zmienić typ przy zachowaniu tej samej nazwy.

Przykład zmiany typu:

```rust
let spaces = "   ";
let spaces = spaces.len();
```

## Typy danych

Rust jest językiem statycznie typowanym: kompilator musi znać typy w czasie kompilacji. Często typ da się wywnioskować, ale czasem trzeba go doprecyzować:

```rust
let guess: u32 = "42".parse().expect("Not a number!");
```

## Typy skalarne

### Liczby całkowite

Główne rodziny:

| Typ | Znaczenie |
|---|---|
| `i8`, `i16`, `i32`, `i64`, `i128`, `isize` | liczby ze znakiem |
| `u8`, `u16`, `u32`, `u64`, `u128`, `usize` | liczby bez znaku |

Praktyczne uwagi:

- domyślny typ całkowity to zwykle `i32`,
- `isize` i `usize` zależą od architektury,
- literały mogą być zapisywane także jako hex, oct, bin i z separatorami `_`.

### Overflow

W trybie debug overflow całkowitoliczbowy powoduje panic. W buildzie release standardowe operacje zawijają się zgodnie z reprezentacją two’s complement. Do jawnej obsługi overflow służą m.in. rodziny metod:

- `wrapping_*`
- `checked_*`
- `overflowing_*`
- `saturating_*`

### Floating point

Rust ma dwa podstawowe typy zmiennoprzecinkowe:

- `f32`
- `f64` (domyślny i zwykle preferowany)

### `bool`

Typ logiczny ma tylko dwie wartości:

```rust
let t = true;
let f: bool = false;
```

### `char`

`char` używa pojedynczych apostrofów i reprezentuje Unicode scalar value:

```rust
let c = 'z';
let z: char = 'ℤ';
let heart_eyed_cat = '😻';
```

To nie jest „bajt znaku ASCII”, tylko 4-bajtowy prymityw Unicode.

## Typy złożone

## Tuple

Tuple grupuje wartości o potencjalnie różnych typach i stałej długości:

```rust
let tup: (i32, f64, u8) = (500, 6.4, 1);
```

Dostęp do danych:

```rust
let (x, y, z) = tup;
let first = tup.0;
```

Szczególny przypadek: pusty tuple `()` to typ unit.

## Array

Array ma stałą długość i jednorodny typ elementów:

```rust
let a = [1, 2, 3, 4, 5];
let a: [i32; 5] = [1, 2, 3, 4, 5];
let a = [3; 5];
```

Najważniejsze cechy:

- wszystkie elementy mają ten sam typ,
- rozmiar jest stały,
- dostęp przez indeks, np. `a[0]`,
- wyjście poza zakres powoduje panic w runtime.

Array jest sensowny głównie wtedy, gdy liczba elementów jest z góry znana i niezmienna; w innych przypadkach zwykle lepszy bywa `Vec`.

## Funkcje

Definicja funkcji używa `fn`, a konwencją nazewniczą jest `snake_case`.

```rust
fn another_function() {
    println!("Another function.");
}
```

### Parametry

Typy parametrów muszą być jawnie zapisane w sygnaturze:

```rust
fn print_labeled_measurement(value: i32, unit_label: char) {
    println!("The measurement is: {value}{unit_label}");
}
```

## Instrukcje a wyrażenia

To jedna z ważniejszych praktycznych zasad Rusta.

- **statement** wykonuje działanie i nie zwraca wartości,
- **expression** oblicza wartość.

Przykład bloku jako wyrażenia:

```rust
let y = {
    let x = 3;
    x + 1
};
```

Tutaj blok zwraca `4`, bo ostatnia linia nie ma średnika. Jeśli dodasz średnik, z wyrażenia robi się instrukcja i wartość nie zostanie zwrócona.

## Zwracanie wartości z funkcji

Funkcja deklaruje typ zwracany po `->`, a domyślnie zwraca wartość ostatniego wyrażenia:

```rust
fn five() -> i32 {
    5
}

fn plus_one(x: i32) -> i32 {
    x + 1
}
```

Można też użyć jawnego `return`, ale typowy styl Rusta preferuje końcowe wyrażenie bez średnika.

## Komentarze

Podstawowy komentarz używa `//`:

```rust
// hello, world
```

Najczęstsze zastosowania:

- osobna linia nad kodem,
- komentarz na końcu linii,
- wielowierszowo przez powtarzane `//`.

## `if` i `else`

`if` w Ruście wymaga warunku typu `bool`.

```rust
if number < 5 {
    println!("condition was true");
} else {
    println!("condition was false");
}
```

W przeciwieństwie do niektórych języków, liczby nie są automatycznie traktowane jako prawda/fałsz.

### `if` jako wyrażenie

`if` zwraca wartość, więc można użyć go po prawej stronie `let`:

```rust
let number = if condition { 5 } else { 6 };
```

Oba ramiona muszą zwracać ten sam typ.

## Pętle

Rust ma trzy podstawowe konstrukcje pętli:

- `loop`
- `while`
- `for`

### `loop`

Najprostsza pętla nieskończona:

```rust
loop {
    println!("again!");
}
```

Sterowanie:

- `break` wychodzi z pętli,
- `continue` przechodzi do następnej iteracji.

`loop` może też zwracać wartość:

```rust
let mut counter = 0;

let result = loop {
    counter += 1;

    if counter == 10 {
        break counter * 2;
    }
};
```

### Etykiety pętli

Przy zagnieżdżonych pętlach można oznaczyć pętlę etykietą i wskazać, której dotyczy `break` lub `continue`, np. `'counting_up`.

### `while`

`while` działa, dopóki warunek jest prawdziwy:

```rust
while number != 0 {
    println!("{number}!");
    number -= 1;
}
```

To czytelniejszy wariant dla „powtarzaj, dopóki...”.

### `for`

Najczęstsza i najbezpieczniejsza forma iteracji po kolekcji:

```rust
let a = [10, 20, 30, 40, 50];

for element in a {
    println!("the value is: {element}");
}
```

Można też iterować po zakresach:

```rust
for number in (1..4).rev() {
    println!("{number}!");
}
```

Przewagi `for` nad ręcznym indeksowaniem:

- mniej kodu,
- mniejsze ryzyko błędu zakresu,
- zwykle lepsza czytelność,
- często lepsza optymalizacja.

## Co zapamiętać

1. Zmienne są domyślnie niemutowalne; `mut` trzeba dodać jawnie.
2. `const` różni się od `let` tym, że wymaga typu i stałego wyrażenia.
3. Shadowing pozwala ponownie użyć tej samej nazwy, nawet przy zmianie typu.
4. Rust mocno rozróżnia instrukcje i wyrażenia; brak średnika często ma znaczenie semantyczne.
5. Funkcje zwykle zwracają wartość przez ostatnie wyrażenie.
6. `if` jest wyrażeniem, ale wymaga warunku typu `bool`.
7. `for` jest preferowaną pętlą do iteracji po kolekcjach, a `loop` i `while` służą bardziej ogólnym wzorcom sterowania.
8. Array ma stały rozmiar i sprawdzane indeksowanie; wyjście poza zakres kończy się panic.
